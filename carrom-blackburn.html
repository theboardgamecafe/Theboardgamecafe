Plan your game

Start with a head-to-head game

Carrom rewards aim and a light touch. It’s easy to try a few practice shots before playing a full board.

Book a table for two

Our carrom tables seat two people each. If you’re coming as four and want to play at the same time, ask if both tables are available.

Get used to the striker

Take a few straight practice shots before aiming for angles. A controlled flick is usually easier to repeat than a hard shot.

Agree how you’ll play the queen

The red queen has a special rule. If you’re playing with official-style rules, agree what covering the queen means before you break.

How is carrom different from pool?

Both use pockets, but carrom is a seated tabletop game. You flick a striker with a finger, while pool uses a cue to hit the cue ball.

How do I request the carrom table?

Use the table request on this page. Include the number of players and tell us if you’d like both tables. We’ll confirm availability.
